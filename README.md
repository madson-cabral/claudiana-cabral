# Bio Site — Claudiana Cabral

Site estático preparado para publicação pelo GitHub Pages. Os arquivos prontos para publicação estão na raiz deste repositório (`index.html`, arquivos CSS/JS e pasta `assets/`).

## Publicar
1. Crie um repositório público chamado `bio-site-claudiana` em https://github.com/new.
2. Envie todos os arquivos desta pasta para a raiz do repositório (não envie o ZIP como arquivo único).
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)`, e salve.
4. O endereço esperado será `https://madson-cabral.github.io/bio-site-claudiana/` depois da publicação.

## Observações
- O formulário de pedido abre uma mensagem no WhatsApp. Não há backend nem armazenamento de pedidos neste site.
- CPF e endereço são coletados apenas no navegador e incluídos na mensagem que a compradora decide enviar pelo WhatsApp.
- A mensagem no WhatsApp não confirma o pagamento nem finaliza automaticamente a compra.
- Antes de publicar, confira o site, os links sociais e as informações da promoção.
